# Hey, I'm Dylan 👋

I'm an engineer focused on **LLM inference, agentic RAG, and evaluation**, with a lot of self-hosting on the side.

I spend most of my time working with Python, PyTorch, vLLM, Kubernetes, TypeScript, and C++.

Lately I've been working on:

* Agentic RAG and LLM inference in production
* Fine-tuning small models, and building evals to check whether it actually helped
* A self-hosted Kubernetes/Proxmox cluster that runs my own models
* Random tools that automate things I don't want to do manually

A couple of public projects:

* [gemma-3-rag-finetuning](https://github.com/dyurillo/gemma-3-rag-finetuning): LoRA fine-tune that gets Gemma 3 1B to cite its sources verbatim (29% → 94%)
* [rag-eval-harness](https://github.com/dyurillo/rag-eval-harness): the eval harness I used to compare it against the base model

Most of my projects live on a **self-hosted GitLab instance**, so I mainly use GitHub to share public projects and contribute to open source.
